## 1. Tool Selection Policy & Rationale

| Technology | Core Responsibility | Why This Tool? | Authoritative Scope |
| :--- | :--- | :--- | :--- |
| **Python 3.11** | Core Data Engineering, Mathematical Algorithms, ML Pipeline & Backend Services | Reproducibility, scientific rigor, algorithmic flexibility, memory efficiency, automated testability, and microsecond-level ML inference. | Curated cleaning, synthetic missing-value experiment, model training, feature selection, and statistical calculations. |
| **KNIME Analytics Platform** | Visual Node-Based Workflow Laboratory | Visual auditability of data-mining operators, educational clarity for non-programmers, and direct compliance with university practicals requiring visual workflow DAGs. | Independent visual workflow executions, visual node comparison, and workflow export records (`.knwf`). |
| **Tableau Desktop / Server** | Enterprise Business Intelligence, Geospatial & Executive Dashboards | Interactive multidimensional filtering, brush-and-link highlighting, treemaps, radial coordinate charts, small multiples, and rapid visual stakeholder exploration. | Presentation-level interactive visual dashboards, business KPIs, and multidimensional slices. |
| **Supabase (Managed PostgreSQL)** | Shared Persistent Storage, Relational Schemas, REST/Realtime Integration | Cloud-scale relational persistence, structured schema isolation (`raw`, `curated`, `analytics`, `models`, `app`), indexing, role-based access, and direct SQL/REST access for external consumers. | Canonical relational storage, dataset version tracking, and shared analytical tables. |
| **FastAPI** | High-Performance REST API Gateway | Strict Pydantic schema validation, asynchronous IO, native OpenAPI/Swagger docs, high throughput, and seamless integration between models and web UI. | Application gateway, schema-enforced inference, and live data serialization. |
| **Next.js & TypeScript** | Interactive Web Application & Scientific Dashboard Frontend | Type safety, modern server/client components, responsive glassmorphism UI, client-side filtering, and web accessibility without external proprietary desktop software. | User-facing interactive visualization, prediction playground, and academic evidence explorer. |
