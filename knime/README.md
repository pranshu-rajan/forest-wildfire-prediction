# KNIME Analytics Platform Integration Guide

This directory provides specifications, node configurations, comparative protocols, and workflow structures for the 6 required KNIME workflows aligning with syllabus Units I–V and Practicals 1–10.

---

## Architecture and Data Contracts

All KNIME workflows consume stable, standardized CSV assets generated by Python in `exports/knime/`:

| KNIME Workflow | Input Data File | Key KNIME Nodes | Expected Output / Checks |
|---|---|---|---|
| **01. Data Quality & Profiling** | `exports/knime/covertype_curated.csv` | CSV Reader, Data Explorer, Statistics, Missing Value, Table Validator | Column summary, zero missing cells confirmed, data type checks |
| **02. Feature Selection & PCA** | `exports/knime/covertype_curated.csv` | Normalizer, Low Variance Filter, Linear Correlation, PCA Apply | Feature ranking, top 10 eigenvalues, 2D/3D PCA projection |
| **03. Classification Comparison** | `exports/knime/covertype_curated.csv` | Partitioning (80/20 Stratified), Decision Tree Learner/Predictor, Random Forest Learner/Predictor, Scorer | Accuracy, Cohen's Kappa, Confusion Matrix comparison vs Python |
| **04. Clustering** | `exports/knime/covertype_curated.csv` | Column Filter (continuous only), Normalizer, k-Means (k=7), Silhouette, Color Manager | Cluster scatter plot, cluster profiles, cross-tabulation with Cover_Type |
| **05. Forest Fires Regression** | `exports/knime/forest_fires_regression_results.csv` | CSV Reader, Math Formula (log1p), Linear Regression Learner, Numeric Scorer | R², MAE, RMSE validation on burned area |
| **06. Preprocessing Experiments** | `exports/knime/covertype_curated.csv` | Normalizer (Min-Max vs Z-Score), Equal Frequency Discretization, Auto-Binner | Before/after distribution histograms, bin boundary verification |

## 1. Workflow: 01_data_quality_profiling

### Goal
Audit schema integrity, verify zero missing values in untouched raw data, and profile distribution statistics.

### Node Pipeline
1. **CSV Reader**:
   - File: `exports/knime/covertype_curated.csv`
   - Settings: Has Column Header = `true`, delimiter = `,`, quotes = `"`
2. **Statistics Node**:
   - Computes: min, max, mean, standard deviation, median, skewness for all 10 continuous predictors.
3. **Missing Value Node**:
   - Verifies 0 missing values across all columns.
4. **Data Explorer**:
   - Generates interactive histogram grid and frequency distributions.

---

## 2. Workflow: 02_feature_selection_pca

### Goal
Reduce feature space and examine continuous terrain variance.

### Node Pipeline
1. **CSV Reader**: Read `covertype_curated.csv`.
2. **Column Filter**: Exclude `Cover_Type` (target label must not leak into unsupervised PCA).
3. **Normalizer**: Z-score standardisation (mean=0, std=1) on the 10 continuous predictors.
4. **PCA Node**:
   - Target dimensions: Retain 95% variance or fix to top 5 components.
   - Output: Loadings table and projected coordinates.
5. **Scatter Plot**: PC1 vs PC2 colored by `Cover_Type` for cluster separability visual check.

---

## 3. Workflow: 03_classification_comparison

### Goal
Train Decision Tree and Random Forest classifiers on the identical 80/20 stratified split used by Python.

### Node Pipeline
1. **CSV Reader**: Read `covertype_curated.csv`.
2. **Partitioning**:
   - 80% Train, 20% Test
   - Partitioning mode: **Stratified** on `Cover_Type`, Random Seed = `42`.
3. **Decision Tree Learner**:
   - Quality measure: Gini index, Max depth: 20, Min records per node: 5.
4. **Decision Tree Predictor**: Test set evaluation.
5. **Random Forest Learner**:
   - Number of models: 100 trees. Attribute sampling: Square root.
6. **Scorer (JavaScript / Standard)**:
   - Evaluates: Accuracy, Balanced Accuracy, Class-wise Recall & Precision.
   - Generates Confusion Matrix matching Python `reports/figures/confusion_matrix_*.png`.

---

## 4. Workflow: 04_clustering

### Goal
Unsupervised topographic grouping with K-Means ($k=7$) and hierarchical agglomerative comparison.

### Node Pipeline
1. **CSV Reader**: Read `covertype_curated.csv`.
2. **Column Filter**: Keep only `Elevation`, `Aspect`, `Slope`, `Horizontal_Distance_To_Hydrology`, `Vertical_Distance_To_Hydrology`, `Horizontal_Distance_To_Roadways`, `Hillshade_9am`, `Hillshade_Noon`, `Hillshade_3pm`, `Horizontal_Distance_To_Fire_Points`.
3. **Normalizer**: Z-score standardization.
4. **k-Means**:
   - $k = 7$, Max iterations = 100.
5. **Cluster Assigner**: Maps cluster IDs back to original unscaled features.
6. **GroupBy**: Computes mean feature vector per cluster to produce the identical profile as `reports/statistics/cluster_profiles.csv`.

---

## 5. Workflow: 05_forest_fires_regression

### Goal
Predict wildfire burned area (`area`) from meteorological features.

### Node Pipeline
1. **CSV Reader**: Read `data/external/forestfires.csv`.
2. **Math Formula**:
   - Formula: `ln(area + 1)` (log1p transformation).
3. **Partitioning**: 80% Train, 20% Test (Seed = 42).
4. **Linear Regression Learner**:
   - Target: `log_area`. Features: `temp`, `RH`, `wind`, `rain`, `FFMC`, `DMC`, `DC`, `ISI`.
5. **Numeric Scorer**: Computes MAE, MSE, RMSE, R².

---

## 6. Workflow: 06_preprocessing_experiments

### Goal
Visual and numeric comparison of Min-Max normalization vs Z-Score standardization and Discretization.

### Node Pipeline
1. **CSV Reader**: Read continuous predictors.
2. **Normalizer (Min-Max)**: Maps to $[0, 1]$.
3. **Normalizer (Z-Score)**: Centers to $\mu=0, \sigma=1$.
4. **Auto-Binner**: Equal frequency binning into 5 bins.
5. **Histogram / Interactive Table**: Directly inspect the variance and range transformations.

---

## Reproducibility & Comparative Protocol

To compare KNIME results with Python:
1. Python metrics are written to `exports/knime/classification_metrics.csv`.
2. In KNIME Scorer, verify that Random Forest test accuracy matches Python within $\pm 1.5\%$ (differences stem from tree implementation heuristics and floating-point threading).
3. Feature rankings between Python Chi-square / Forest Importances and KNIME Correlation / Information Gain align on `Elevation` as the top explanatory predictor.
